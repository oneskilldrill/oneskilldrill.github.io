# One Skill Drill

Short interactive practice drills: one skill, five scenarios, instant feedback, and a score.

Live: https://oneskilldrill.github.io/

Static HTML/CSS/vanilla JS in `docs/`, served by GitHub Pages from the `main` branch. Each drill is a folder with an `index.html` shell and a `drill.js` data file read by the shared engine in `site/engine/`.

Independent practice content. Not affiliated with or endorsed by Microsoft.
